# 🚗 Vehicle Product Sales Analysis

## 📌 Project Overview
This project analyzes vehicle product sales data using Microsoft Excel to identify sales trends, product performance, customer behavior, and regional performance. The analysis provides meaningful business insights to support data-driven decision-making.

## 📊 Dataset
The dataset contains vehicle product sales information, including:
- Product details
- Sales and order information
- Customer details
- Geographic/market information
- Revenue-related metrics

## 🛠️ Tools & Technologies
- Microsoft Excel
- Excel Functions
- Data Cleaning
- Data Analysis
- Pivot Tables
- Charts & Visualizations
- KPI Analysis

## 🔍 Key Analysis
- Sales performance analysis
- Product-wise sales analysis
- Customer and order analysis
- Regional/market performance
- Identification of sales trends
- KPI-based business insights

## 📈 Project Workflow
1. Imported the vehicle sales dataset into Excel.
2. Cleaned and prepared the data for analysis.
3. Performed exploratory data analysis.
4. Created Pivot Tables and calculated key metrics.
5. Developed charts and visualizations.
6. Identified important sales trends and business insights.

## 💡 Key Outcomes
- Identified high-performing vehicle products.
- Analyzed sales patterns across different markets.
- Evaluated customer and order trends.
- Generated KPIs to understand overall sales performance.
- Provided insights to support business decision-making.
